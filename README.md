## 📖 项目简介

本项目是一个以《弹丸论破》系列游戏为主题的粉丝网页，采用**苹果官网风格**设计，融合了高级毛玻璃效果、动态霓虹光效、3D 轮播等现代前端技术，为访客带来沉浸式的视觉体验。

### 🎯 项目特点

| 特性 | 描述 |
|------|------|
| 🎨 **苹果风格设计** | 简洁大气的布局，毛玻璃材质，高级感十足 |
| ✨ **动态霓虹光效** | 粉色、蓝色、绿色霓虹粒子，打造赛博朋克氛围 |
| 🎭 **3D 立体轮播** | 首页 3D 旋转背景，点击切换展示不同场景 |
| 📱 **响应式布局** | 完美适配桌面、平板、手机等各种设备 |
| 🖱️ **自定义光标** | 粉色光点 + 蓝色光环，悬停时放大变色 |
| 💫 **滚动动画** | 元素进入视口时淡入上浮，流畅自然 |
| 🔢 **数字雨特效** | Matrix 风格多色字符雨，致敬经典 |
| ⌨️ **打字机效果** | 副标题循环打字展示，增添科技感 |

## 🎮 游戏系统

### 学级裁判 (Class Trial)

本作的核心系统，融合推理与动作的独特玩法：

| 玩法 | 说明 |
|------|------|
| 💬 **无休止议论** | 高速飞过的发言字幕，用言弹击破矛盾 |
| 🎯 **反驳热辩** | 弹幕射击风格的辩论环节 |
| 🍣 **逻辑推理** | 旋转寿司带上匹配正确证据 |
| 🎹 **节奏辩论** | 音乐节奏游戏风格的辩论 |
| 🧩 **拼字游戏** | 排列正确词汇组成完整句子 |
| 🗳️ **最终投票** | 投票指认凶手，决定生死 |

### 游戏流程

```
日常生活 → 发现尸体 → 搜查阶段 → 学级裁判 → 投票 → 处刑/毕业
```

## 🚀 快速开始

### 本地运行

```bash
# 克隆项目
git clone https://github.com/muxier-520/-.git

# 进入项目目录
cd -

# 启动本地服务器（Python）
python -m http.server 8080

# 或使用 Node.js
npx http-server -p 8080
```

### 访问网站

打开浏览器访问：**http://localhost:8080/html/index.html**

## 🎨 设计理念

### 配色方案

| 颜色 | 用途 | 代码 |
|------|------|------|
| 💗 霓虹粉 | 主色调 | `#ff00cc` |
| 💙 科技蓝 | 辅助色 | `#00ffff` |
| 💚 生机绿 | 点缀色 | `#00ff88` |
| 💜 梦幻紫 | 特效色 | `#8b5cf6` |

### 设计原则

1. **苹果风格** — 简洁大气，留白充足
2. **赛博朋克** — 霓虹光效，科技感十足
3. **弹丸论破** — 经典配色，致敬原作
4. **用户体验** — 流畅动画，响应迅速
