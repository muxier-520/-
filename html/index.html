BACKGROUND

背景介绍

私立希望之峰学园，这是一所集结了所有领域超一流高中生的特权学校。据说只要从这里毕业，就等于掌握了人生的成功。然而，平凡的主角苗木诚与其他14名拥有"超高校级"才能的学生，在踏入校门的瞬间却失去了意识。醒来后，他们发现自己被关在了这所门窗紧闭、与世隔绝的学园之中。

自称校长的神秘玩偶"黑白熊"出现在他们面前，宣读了令人绝望的规则："若想离开这里，就必须杀掉某个人。" 在这极限的心理压力下，学生们被迫开始了一场赌上生死的"自相残杀校园生活"。

当杀人事件发生后，幸存者必须通过"学级裁判"找出真凶。如果指认正确，凶手将被残酷处刑；如果指认错误，则凶手毕业，其余全员处刑。在谎言与背叛交织的辩论中，他们必须利用搜查到的证据作为"言弹"，击碎对手的谎言，查明真相并试图逃离这所绝望学园。

🏫

希望之峰学园

创立于二战后的精英学校，专门培养各领域的天才。学园拥有高度自治权，甚至可以无视政府法律。其真实目的是为了培养能够引领社会的领袖人才，但背后隐藏着不为人知的黑暗秘密。

🐻

黑白熊

自称学园校长的半黑半白玩偶熊，是"自相残杀"的始作俑者。右半身纯白可爱，左半身漆黑狰狞，象征着希望与绝望的对立。其真实身份与幕后黑手"江之岛盾子"有着千丝万缕的联系。

💀

自相残杀

黑白熊制定的绝望规则：学生之间可以自由杀人，但杀人者必须隐瞒身份。如果在学级裁判中未被找出，杀人者将"毕业"离开，其余人全部处刑。这种残酷的规则将人性推向了极限。

⚖️

学级裁判

当杀人事件发生后，幸存者必须聚集在一起进行辩论，找出真凶。这是希望与绝望的终极对决——用收集到的证据"言弹"击碎谎言，在谎言与背叛中寻找唯一的真相。

SYSTEM

游戏玩法

高速推理动作 学级裁判

本作的核心玩法是"无休止议论"。在搜查阶段收集证据后，所有学生将聚集在法庭上进行辩论。玩家必须在高速飞过的发言字幕中，找出对手的逻辑矛盾。

利用收集到的线索化为"言弹"，像射击游戏一样瞄准并击破谎言！这不仅是逻辑的比拼，更需要在这场"高速推理动作游戏"中，于紧张的倒计时下通过节奏按键、拼字游戏等环节揭开唯一的真相。

NONSTOP DEBATE

游戏流程 / GAME FLOW

01

日常生活的部分

在学园中自由探索，与同学们交流，增进感情，收集情报。这是暴风雨前的宁静。

02

搜查阶段

发现尸体后进入搜查模式。在学园各处寻找线索，收集证据化为"言弹"，为学级裁判做准备。

03

学级裁判

所有幸存者聚集辩论。通过"无休止议论"等环节，用言弹击破谎言，找出真凶。

04

投票与处刑

最终投票指认真凶。正确则凶手被处刑，错误则全员处刑。生死就在一念之间。

CLASS TRIAL

学级裁判系统

学级裁判是《弹丸论破》系列的核心系统，融合了推理与动作的独特玩法。玩家需要在高速进行的辩论中，找出矛盾并用"言弹"击破谎言。

💬

无休止议论

最基本的辩论形式。发言者的言论会以字幕形式高速飞过，玩家需要在合适的时机选择正确的"言弹"击破矛盾发言。

NONSTOP DEBATE
🎯

反驳热辩

弹幕射击风格的辩论环节。玩家需要操控言弹，在弹幕雨中瞄准并击破对手的反驳，类似射击游戏的玩法。

REBUTTAL SHOWDOWN
🍣

逻辑推理

在旋转寿司带上，玩家需要将正确的证据与问题匹配。需要在有限时间内找出正确的逻辑链条。

LOGIC DRIVE
🎹

节奏辩论

音乐节奏游戏风格的辩论。玩家需要按照节拍按下正确的按键，在节奏中找出真相。

RHYTHM BATTLE
🧩

拼字游戏

通过排列正确的词汇组成完整的句子，揭露事件的真相。考验玩家的语言组织能力。

PANIC DEBATE
🗳️

最终投票

辩论结束后，所有幸存者投票指认凶手。这是决定生死的关键时刻。
